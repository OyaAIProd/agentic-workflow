# Contributing to Agentic Workflow

Thank you for your interest in improving this methodology. Contributions are welcome and appreciated.

---

## How to Contribute

### Reporting Issues

If you encounter problems or have suggestions:

1. Check existing issues to avoid duplicates
2. Open a new issue with a clear title
3. Describe the problem or suggestion in detail
4. Include context (your setup, what you tried, etc.)

### Proposing Changes

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-improvement`)
3. Make your changes
4. Test your changes in a real project
5. Commit with clear messages
6. Open a Pull Request

### Commit Message Format

```
type: short description

Longer explanation if needed.

Signed-off-by: Your Name <your.email@example.com>
```

Types:
- `docs`: Documentation changes
- `feat`: New features
- `fix`: Bug fixes
- `refactor`: Code restructuring
- `chore`: Maintenance tasks

## Code of Conduct

### Be Respectful

- Treat all contributors with respect
- Welcome newcomers
- Provide constructive feedback

### Be Rigorous

- Test your contributions
- Document your changes
- Follow existing conventions

### Be Honest

- Acknowledge limitations
- Credit sources and inspirations
- Admit when you're unsure

---

## Documentation Standards

When contributing documentation:

- Use bilingual approach (EN primary, FR welcome)
- No emoji in technical documentation
- Scholar/scientist style: precision, structure, neutrality
- Include author signature and date

```markdown
---
Author: Your Name
Date: YYYY-MM-DD
```
